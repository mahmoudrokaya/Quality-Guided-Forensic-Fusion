How to use the external files
1. Open the SharePoint folder link above.
2. Download the files needed for the experiment you want to reproduce, subject to access and licensing restrictions.
3. Consult the repository's LARGE_FILES_MANIFEST.csv, DATA_AVAILABILITY.md, and REPRODUCIBILITY.md (where available) for expected relative paths and workflow guidance.
4. Restore the downloaded files to the relative directories expected by the corresponding scripts. Verify filenames, versions, and integrity before running analyses.
The external folder may contain source datasets, processed data, and experiment outputs. Do not assume that every file in the external folder may be redistributed: third-party datasets and other materials remain subject to their original licenses and terms.
Scope of this branch
This branch is an access pointer and documentation location, not a complete data archive. The GitHub publication copy was prepared with a 25 MiB per-file exclusion threshold, so large files were omitted from that copy. An external link does not constitute a permanent, versioned archival deposit.
